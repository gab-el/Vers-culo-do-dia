# 📖 Versículo do Dia com Trilha Sonora

Um site clean, responsivo e contemplativo desenvolvido para exibir versículos bíblicos diários de forma dinâmica, integrada a uma experiência musical imersiva através do Spotify.

O projeto consome uma API externa em tempo real para buscar as escrituras e conta com um design totalmente sintonizado com a identidade visual do player de música.

---

## 🚀 Funcionalidades

* **Busca Dinâmica de Versículos:** Consome uma API para carregar trechos bíblicos e suas respectivas referências instantaneamente.
* **Integração com Spotify Embed:** Um player lateral elegante fixado na tela para acompanhar a leitura com uma trilha sonora instrumental/calma.
* **Design Sintonizado:** Paleta de cores baseada em tons quentes de marrom, bronze e café, gerando uma atmosfera relaxante e sofisticada.
* **Tipografia Elegante:** Uso de fontes serifadas sofisticadas (`Playfair Display`) importadas via Google Fonts.
* **Totalmente Responsivo:** Layout adaptável que reposiciona o player e o título automaticamente para garantir uma excelente experiência em dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do projeto.
* **CSS3:** Estilização avançada utilizando Flexbox, posicionamento absoluto/fixo, gradientes personalizados e Media Queries para responsividade.
* **JavaScript (ES6+):** Manipulação do DOM, tratamento de eventos de clique e requisições assíncronas (Fetch API / Async-Await) com tratamento de erros.
* **Spotify API / Embed:** Incorporação do widget oficial de áudio.

---

## 🎨 Layout

O design foi planejado para equilibrar modernidade e sobriedade:
* **Fundo:** Gradiente suave que transiciona do marrom-escuro (casando com o player) para o bronze/areia.
* **Cartão Central:** Um bloco claro (`#fcfaf2`) em estilo *card* moderno com cantos arredondados e sombra profunda para dar profundidade ao texto principal.
